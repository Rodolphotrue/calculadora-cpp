# 🧮 Calculadora em C++

## 📌 Descrição
Calculadora em C++ com menu interativo, desenvolvida para praticar lógica de programação, controle de fluxo e validação de dados.

## 🚀 Funcionalidades
- Soma
- Subtração
- Multiplicação
- Divisão (com validação)
- Menu com repetição (`do while`)

## 💻 Tecnologias
- C++
- Dev-C++

## ▶️ Como usar
Execute o programa e escolha a operação desejada no menu.

## 🧠 Aprendizados
- Estrutura `switch case`
- Laço `do while`
- Entrada e saída de dados
- Validação de erros

## 📈 Melhorias futuras
- Histórico de cálculos
- Salvamento em arquivo
- Versão com `class`
